# dsh-currency · 货币格式化与换算

纯 Node 实现，无网络、无外部服务。

## 安装

```bash
dsh plugin add dsh-currency
```
安装后在 profile 的 `package.json` 的 `dsh.profile.bundles` 中加入 `"dsh-currency"`。

## 安装

```bash
dsh plugin add github:uckkk/dsh-currency
```

## 使用

安装后在会话中调用该插件注册的工具即可。
